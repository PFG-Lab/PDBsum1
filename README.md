# PDBsum1
PDBsum1 is a standalone version of PDBsum Generate for local installation and running. It provides an at-a-glance overview of the contents of each PDB file processed, showing the molecule(s) that make up the structure (ie protein chains, DNA, ligands and metal ions) and schematic diagrams of the interactions between them.

<H4>Installation</H4>

To install, download the following files:

<UL>
  <LI><B>pdbsum1.tar.gz</B> - gzipped tar file of the PDBsum1 programs
  <LI><B>docs.tar.gz</B> - documentation
</UL>

Extract all the files from the above compressed archives. Then follow the instructions in <B>install.html</B> (from the extracted <B>docs.tar.gz</B> file).
